Core Thesis

The Trebuchet Pulse is a fictional kernel for studying compression, acceleration, and release. It does not model a real attack. It models a bounded symbolic pulse: coil three times, accelerate through a 3×3×3 move lattice, compress to zero, release into a local dummy field, report, reset.

No-Bleed Boundary

The release is not externalized. It resolves into a dummy field and then returns to zero. This keeps the model useful as a design artifact without turning it into an operational weapon.
